# LaserGRBL G-code 生成器 · 使用手册

适用版本：**v1.20.0** ｜ [English version](MANUAL.en.md) ｜ 本手册随版本发布同步更新，历史改动见 [CHANGELOG](../CHANGELOG.md)。

本工具为单个 HTML 文件，使用浏览器打开即可运行（推荐 Chrome 或 Edge），无需安装。工具面向机械臂绘画工作流设计：振动马达撒布火药粉，激光点燃，两种工具配合作业；也可作为普通激光雕刻/切割的 G-code 生成器使用。

## 术语表

手册中反复出现以下术语，阅读时可随时回到本表查阅：

| 术语 | 含义 |
|---|---|
| **G-code** | 机器可执行的指令文件，每行一条命令，内容为"移动到某位置、输出多大功率" |
| **.nc 文件** | G-code 的文件格式。下载后在 LaserGRBL 中运行 |
| **S 值** | 指令中的强度数值。对激光表示功率大小，对马达表示振动强度 |
| **$30** | 机器内部的一项设置，表示 S 值的最大量程。LaserGRBL 默认为 1000 |
| **功率% 与 S 的换算** | 功率% = S ÷ $30 × 100。当 $30=1000 时，S450 为 45%，S45 仅为 4.5%，输入时注意位数 |
| **F 值** | 移动速度，单位为毫米/分钟。F600 即每分钟 60 厘米 |
| **振幅** | 撒粉马达的振动强度（同样以 S 值表示）。振动越强，粉线越粗 |
| **M3 / M4** | 两种开启激光/马达的指令。M3 为恒定强度；M4 在加减速时自动调整强度。撒粉固定使用 M3，激光雕刻一般使用 M4 |
| **M0** | 暂停指令，机器停下等待人工操作。双工序流程通过它停机换工具头 |
| **purge（预冲）** | 正式撒粉前，先在指定位置空撒数秒，使管路中的粉恢复流动 |

## 1. 快速上手

1. 用浏览器打开 `gcode_generator.html`；
2. 在页面顶部选择**作业模式**（激光 / 振动马达 / 双工序）；
3. 将 SVG 文件拖入导入区；
4. 在"图层参数"中为每个颜色图层设置参数；
5. 等待预览刷新（复杂图形在后台计算，界面不会卡顿）；
6. 点击"下载"获得 `.nc` 文件，在 LaserGRBL 中运行。

> 示例：在 Illustrator 或 Inkscape 中绘制一个黑色描边的圆，导出为 SVG 并拖入工具。工具自动识别出一个黑色图层；路径模式选择"描边"，功率设为 30%、速度 1800，点击下载。生成的 G-code 将沿圆周走一圈。

---

## 2. 导入文件（SVG）

无论使用 Illustrator、Figma 还是 Inkscape 绘制，只要线条颜色不同，导入后即自动分为不同的图层，无需任何特殊设置。图中使用了几种颜色，就会得到几个图层，每个图层的参数可单独设置。

> 示例：若希望"先撒粉的笔画"与"仅激光的细节"分开控制，在设计软件中将两者绘制为不同颜色（如红色与黑色）即可，导入后即为两个独立图层。

## 2.5 参数记忆与工程文件

**自动记忆**：所有全局设置和每个颜色图层的参数（功率、速度、模式、笔画风格等）自动保存在本机浏览器中。刷新页面或次日再次打开，设置原样恢复；重新导入使用相同颜色的 SVG 时，每个颜色自动套用上次的参数。诸如"红色 = 构造线 S550 F600"的对应关系设置一次即长期有效。

**工程文件**：点击导入区的"保存工程"，可将 SVG 图形与全部参数（含撒粉档案）打包为一个 `.json` 文件下载；"载入工程"可一键完整恢复。建议不同作品或参数方案各保存一个工程文件，用于长期存档或跨设备迁移。

> 注意：清除浏览器数据会同时清除自动记忆。重要参数请保存为工程文件。

**工程命名**：点击"保存工程"后会弹出输入框，可为工程命名（默认使用 SVG 文件名），文件按 `工程名.json` 下载。名称保存在工程内，下次保存时自动带出。

**G-code 文件名**：下载的 `.nc` 文件自动使用导入 SVG 的文件名，如 `dragon.svg` 生成 `dragon.nc`。载入工程后同样生效。校准测试图固定命名为 `calib.nc`。

## 3. 全局设置

| 设置项 | 说明 |
|---|---|
| 输出宽度 (mm) | 成品的实际宽度。高度按原图比例自动计算 |
| 原点 | 左下角（坐标均为正数）或居中（原点位于图形中心） |
| S 上限 (=机器里的$30) | 须与机器内 `$30` 设置一致，否则功率百分比不准确。LaserGRBL 默认为 1000。功率/振幅输入框旁实时显示对应的 S 值 |
| 空程 G0 | 抬笔快速移动的速度，用于时间估算 |
| 气泵/风扇 (M8/M9) | 勾选后在作业开始时开启、结束时关闭 |
| 加工前走边框对位 | 正式加工前，机器以零功率沿图形外框走一圈，用于确认位置和尺寸。启用"按实际画布摆放"时改为沿**画布外框**行走，见 第 3.5 节 |
| 按实际画布摆放 | 填写实际画布尺寸（英寸或毫米），并设置图形在画布内的位置，见 第 3.5 节 |
| 以当前停的位置为起点 (G92) | 将机械臂当前停靠位置设为本次作业的起点。起点不固定的大幅面作业建议开启 |
| 马达偏移 dX/dY | 撒粉喷口与激光光点的位置差值，测量方法见 第 9.6 节 |
| 撒粉前预冲 (purge) | 正式撒粉前先移动到指定位置空撒数秒，见 第 9.5 节 |

## 3.5 按实际画布摆放（画布对位）

用于解决图形画出画布范围、或与画布对不准的问题。启用后：

1. **填写画布尺寸**：宽 × 高，单位可选英寸或毫米（10×10 英寸的画布填 10 和 10）；
2. **选择图形位置**：「居中」将图形置于画布正中；也可直接**在预览中按住图形拖动**，将其移动到画布内的任意位置（松开后生效，位置自动切换为「自定义」，数字框同步更新）；「自定义」下的数字框可用于精确微调（图形距画布左边和下边的距离）；
3. 预览中显示**棕色画布外框**及左下角的零点标记，图形在画布内的位置一目了然；图形超出画布时显示**红色警告**；
4. **坐标零点即画布左下角**。开始作业前，将喷口尖（或激光光点）对准画布左下角后置零；
5. 勾选"加工前走边框"后，机器先以零功率沿画布外框走一圈，随后暂停（M0）。观察走出的框与实际画布边缘是否重合：重合则在 LaserGRBL 中按继续开始加工；不重合则点击停止，移动画布或重新置零后再次运行。

> 提示：若走出的框整体倾斜，说明画布摆放倾斜，将画布移动至与框重合即可（框的位置即实际加工位置）。若机械臂被碰动过，重新将喷口对准画布左下角置零，再走一遍边框确认。

**默认速度**：新图层默认 F=1000（激光）/ F=3000（马达）；切换设备或作业模式时恢复对应默认值。已使用过的颜色优先恢复上次参数。

**加工顺序**：图层列表自上而下即为加工顺序（角标 #1、#2 …）。点击「编辑顺序」进入拖动模式（卡片折叠、可拖动调整），点击「完成」锁定。双工序模式下撒粉图层始终先于激光图层执行，列表顺序仅决定各工序内部的先后。

**全选与连选**：图层启用列、测试页的导出列和选中列均设有「全选」框；所有勾选框支持 **Shift 连选**：点击一个，按住 Shift 点击另一个，两者之间的整段随之变化。

**其他**：修改参数后光标自动回到原输入框（按 Tab 可依次跳转）；工具无"生成"按钮（始终自动生成），下载按钮位于左栏最底部（滚动到底部可见），其下方的状态行显示"计算中 Ns…"或"就绪"。

## 4. 路径模式（激光图层）

每个图层可单独选择：

- **描边（outline）**：沿绘制的轮廓走一遍。适用于切割和线稿。
- **中线（centerline）**：对有宽度的笔画形状仅沿中间走一遍。适用于将描边字体转为单线雕刻。
- **填充（fill）**：以平行线扫满闭合形状的内部。参数见 第 5 节。
- **加粗（thicken）**：将单线向两侧加宽为有宽度的笔画并填充。适用于单线字体、手写路径。参数见 第 6 节。
- **圆圈（circles）**：沿线条每隔一段绘制一个圆圈，原线条本身不绘制。圆圈**大小**与**间隔**均可选择固定或随机（随机结果在同一文件的每次生成中保持一致）；勾选"填充圆圈"生成实心圆，并可设置**填充密度**（单位 mm，数值越小填充越密实）。

---

## 5. 填充参数

- **间距 (mm)**：相邻扫描线的间隔。表面雕刻常用 0.1~0.2；需刻透厚材料时可用 0.05 并增加遍数。
- **线迹方向**：
  - **固定角度**：所有扫描线沿同一方向，为传统方式。
  - **垂直于笔画**：每条扫描线垂直横穿笔画，长度约等于笔画宽度。用于解决厚材料上"部分区域刻得透、部分刻不透"的问题：长线中段机器全速运行、烧灼较浅，短线因加减速烧灼较深，因此不同朝向的笔画受热不均；改为"垂直于笔画"后所有线迹长度一致，各处烧灼深度一致。转角与交叉处自动处理，不遗漏、不重复。
- **自动回退**：过于宽胖、不具笔画形态的图形（如实心圆盘）无法提取中线，此时自动改用固定角度填充。
- **填充+描边**：勾选后在填充完成后沿轮廓再描一圈，边缘更整齐。

> 示例（厚卡纸刻字、烧灼不均的场景）：间距 0.05，线迹方向选"垂直于笔画"，S30 F1800，雕刻模式（M4），并确认机器内 `$32=1`。

## 6. 加粗模式与笔画风格

**笔画宽度**滑块设定基准宽度（mm）。**笔画风格**决定粗细沿笔画的变化方式：

| 风格 | 效果 | 适用 |
|---|---|---|
| 均匀 | 全程等宽 | 标准粗线 |
| 两端收锋 | 起笔与收笔处平滑收细，类似钢笔的入锋出锋 | 手写效果 |
| 书法笔锋(斜切) | 粗细随笔画方向变化（横细竖粗）。**笔锋角度**可调：30° 为西文斜体的常用角度，0° 接近宋体笔意 | 书法字 |
| 毛笔 | 收锋与笔锋效果叠加 | 签名、题款 |
| 火药爆破 | 粗细随机起伏，边缘带灼烧短刺，周围有飞溅火花。同一文件每次生成的结果完全一致 | 爆炸/火药美学 |

加粗模式的填充同样支持"垂直于笔画"方向，且短线长度随局部宽度变化：收锋处短线自动缩短，烧灼保持均匀。闭合路径没有起笔与收笔，收锋风格自动退化为均匀（毛笔退化为纯笔锋）。

## 7. 作业模式

页面顶部第 0 节用于选择本次作业的模式，界面仅显示该模式相关的设置：

| 模式 | 行为 |
|---|---|
| **激光雕刻** | 所有图层为激光；撒粉相关设置隐藏；材料预设可用 |
| **振动马达撒粉** | 所有图层为撒粉；材料预设隐藏（属于激光材料的概念）；马达偏移隐藏（单一工具时使用"以当前位置为起点"即可）；purge 可用 |
| **双工序（先撒粉后激光）** | 每个图层可单独选择设备；全部设置可见；生成的 G-code 分为两段，中间以 M0 暂停换工具 |

模式选择自动记忆，下次打开保持上次的选择。

## 8. 设备与双工序（撒粉 + 激光）

每个图层顶部设有**设备**选项：**激光** 或 **振动马达（撒粉）**。两种工具共用同一路控制信号，因此按"先完成一种工序、停机换工具、再执行另一种"的流程生成 G-code：

```
G92 X0 Y0            ← 可选：以当前位置为起点
(purge 预冲)          ← 可选
; PHASE 1 / POWDER   ← 全部撒粉图层（M3 恒定，坐标已含马达偏移）
M0                   ← 暂停：换装激光头后，在 LaserGRBL 中按继续
; PHASE 2 / LASER    ← 全部激光图层（坐标不含偏移）
```

撒粉图层始终排在激光图层之前，与列表顺序无关。仅使用单一设备时不产生 M0。

## 9. 撒粉图层详解

### 9.1 工作原理

激光类似"细笔填色"（往复扫描填满面积），撒粉类似"粗笔一笔成形"：粉线的粗细由振幅直接控制。**中线**模式下，马达图层仅沿线条中间走一遍（开放线条按原样行走，闭合形状自动提取中线），粗细节奏编码在沿途逐段变化的 S 值（即振幅）中。撒粉使用 **M3 恒定模式**而非 M4：M4 会在加减速时同步降低振幅，导致粉流不稳定。

**撒粉路径模式**：马达图层有四种路径模式——**描边**（默认：沿轮廓原样走一遍，振幅恒定）、**中线**（沿中间行走，带粗细节奏）、**填充**（闭合形状内部铺设平行粉线，振幅恒定；粉线本身有数毫米宽，间距建议不小于 2mm）、**圆圈**（圆点撒粉：沿线每隔一段停留一点，保持振动数秒，粉末堆积成圆点；间隔与停留时间均可固定或随机；圆点大小由停留时间和振幅共同决定，需实际测试确定）。描边、填充、圆圈模式的振幅均使用单一「振幅%」值。

### 9.2 粉线粗细节奏与振幅换算

选择笔画风格（均匀/收锋/笔锋/毛笔）确定设计上的粗细节奏后，工具自动换算为振幅：设计中最细处对应所设最小振幅，最粗处对应最大振幅，中间按比例取值。即使设计中的粗细差异很小，也会被拉伸至硬件可表现的最大反差。

**均匀笔画**：选择"均匀"时整条线等宽，界面仅显示一个**「振幅 %」**输入框，G-code 直接使用该值；最小/最大振幅、粗细反差、提前量仅在变宽笔画（收锋/笔锋/毛笔）下显示。

- **最小/最大振幅 %**：未使用组件档案时的振幅换算范围；
- **粗细反差**：调整反差的夸张程度。调大则细处更细（笔锋更尖锐），调小则整体更饱满。默认为 1（不夸张）；
- **提前量 (mm)**：粉末从喷口落到画布存在延迟。该参数使振幅变化提前相应距离发出，以抵消延迟。笔画末端出现拖粉时调大此值（建议从 3mm 开始尝试）。

### 9.3 组件档案

每套"3D 打印撒粉件 + 粉料"组合的物理特性不同（出粉粗细、起始出粉的最小振幅、饱和上限等）。**组件档案**保存每套组合实测的"振幅→线宽"对应关系；在图层中切换档案，即自动按该组合的实测数据换算。选择"不用校准数据"则不查曲线，直接按振幅范围换算。

### 9.4 校准向导

在马达图层点击"校准向导…"：

1. **生成测试图案 G-code**，下载 `calib.nc`（8 条振幅从 20% 到 90% 逐级递增的直线，每条 30mm）；
2. 装粉运行；
3. 用卡尺测量每条粉线的实际宽度并填入表格（**未出粉的行填 0**，工具将记录该振幅以下不出粉）；
4. 保存档案。

> 示例校准结果：30%→1.2mm、50%→2.0mm、70%→3.1mm、80%→3.5mm、20% 填 0（不出粉）。此后该档案下，振幅仅在 30~80% 的有效范围内取值。

**快速漂移校准**（建议每个作业日执行）：粉量、湿度会使出粉量逐渐变化。以基准振幅（如 60%）画一条线，测量宽度后填入"今日实测"，点击缩放按钮，整条曲线按比例修正，无需重新完整校准。

**保存机制**：向导内的全部改动（表格数值、新建/删除档案、漂移校准）均为草稿，点击「保存档案」后方才生效并参与 G-code 生成；带未保存改动关闭窗口时弹出确认。误删档案时直接关闭窗口即可回滚。

### 9.5 Purge 预冲

停机一段时间后，管路中的粉末流动性下降，直接开始作业会导致第一笔不完整。勾选 purge 后，正式路径开始前自动移动到指定坐标（建议选择画面外的废料区）空撒指定秒数，恢复粉流。

### 9.6 马达偏移测量

撒粉喷口与激光光点的物理位置不同，须测量一次：以低功率激光绘制一个小十字 → 换撒粉头在**同一坐标**撒一个十字 → 测量两个十字中心的偏差 → 填入 dX/dY。此后撒粉工序的坐标自动平移，粉线与激光在画布上重合。工具头不经拆装则无需重新测量。

## 10. 材料预设

"材料预设"下拉菜单可一键套用某种 材质/厚度/火药/效果 对应的 模式/功率/速度/遍数。预设管理器支持新建、从当前图层保存、删除、导入导出 JSON、恢复内置库。数据保存在本机浏览器中。

**火药栏**：预设中设有自由填写的"火药"字段（建议格式：厂家·颜色·粗细·批次，如"XX厂·黑·细·2026-07批"）。点燃参数取决于**火药与画布的组合**，无法拆分推算，一条预设即记录一个实测过的组合。

> 注意：预设中的数值在实际测试验证之前仅作参考。

**草稿与保存**：管理器内的全部改动（编辑、新建、删除、导入、载入内置）均为草稿，点击底部「保存预设」后方才生效。带未保存改动关闭窗口时弹出确认；误改误删直接关闭窗口即可回滚。「导出 JSON」导出的是当前草稿。

## 10.5 测试页签

左栏顶部设有两个页签：**「创作」**（完整 SVG 工作流）与**「测试」**。切换到「测试」后，左栏整体变为测试工作台，进入即自动生成 G-code，此后任何改动实时更新。用于材料与火药的参数定标：

**T1 · 布局与步进**：以滑选格子的方式选择行×列（操作与文档软件的插入表格类似，也可直接输入数字，最大 20×20）；设置线长、行距、列距；选择设备（激光/马达）。S 与 F（马达为振幅%）各设**行步进与列步进**：每格的值 = 起始值 + 行号×行步进 + 列号×列步进，不需变化的方向填 0。「填充S / 填充F / 填充振幅」为三个独立按钮，仅重新计算对应变量，不影响已手动修改的其他数值。激光的 S 直接填数值（上限为所设 $30），M3/M4 可选；马达按振幅% 填写、F 为固定值（自动使用 M3）。

**T2 · 线列表**：每条线对应一个颜色，预览与列表色块一一对应。勾选框控制**该线是否导出**（不勾选则不进入 G-code）；**点击卡片本身为选中**（整卡高亮），Shift 点击为连选，点击勾选框或数字框不触发选中；每条线的 S/F（或振幅%）可单独修改，修改后立即重新生成。**在预览画布上按住 Shift 拖动为框选**：矩形触及的线全部选中（选中线在预览中加粗显示），横向拖动即选中一行、纵向拖动即选中一列；普通拖动仍为平移画面。

**T3 · 组**：选中若干条线后点击「把选中的线成组」。组可重命名；组的勾选框一键开关全组导出；在组内填写一次 S/F/振幅即批量应用到全组；组内线条在预览中统一使用组的颜色；「解组」还原。G-code 注释中带组名（`; r2c3 [组1]: S500 F900`）。

其他说明：顶部统计栏（空程/加工长度/预估耗时/行数）同样生效（网格按格子顺序行走，不做空程优化）；第 1 行位于下方（Y=0）；每格带注释，并提供可复制的参数对照表；页签选择、布局、每线参数、导出勾选、分组均自动记忆；「下载 testgrid.nc」位于测试面板底部。

**关于弹窗**：本工具的全部弹窗（工程命名框、各类确认与提示）均为页面内置对话框，不使用浏览器原生弹窗，因此不受浏览器"阻止对话框"设置的影响。

## 11. 预览与统计

- 滚轮缩放、拖动平移、双击复位；
- **绿色虚线**为空程（抬笔快速移动）路径；路径数量超过 8000 条时自动隐藏以保持流畅；
- 马达图层以**变宽线条**绘制，可直接观察粉线的粗细节奏；
- 鼠标悬停在图层卡片上时，预览中高亮该图层；
- 统计栏显示：优化前/后空程、节省比例、加工长度、预计时间、G-code 行数。

**性能说明**：全部重计算在后台执行，调整参数时界面不卡顿；连续修改时仅计算最新一次。仅修改功率/速度/遍数等不改变走线形状的参数时，结果几乎即时更新。特别长的 G-code 在文本框中仅显示开头部分，**下载的文件始终完整**。

## 13. 常见问题

**导入 SVG 后只有一个黑色图层？** 旧版本的问题，现已修复。若仍出现，请检查 SVG 是否确实只使用了一种描边颜色。

**厚材料部分区域刻不透？** 参见 第 5 节：填充线迹方向改为"垂直于笔画"，确认机器内 `$32=1`、雕刻使用 M4。仍刻不透时增加遍数，不建议持续降低速度。

**"垂直于笔画"填充结果为空？** 图形过于宽胖、不具笔画形态，工具已自动改用固定角度填充，属正常现象。

**撒粉笔画末端粉末堆积？** 调大提前量，见 第 9.2 节。

**第一条粉线不完整？** 开启 purge 预冲，见 第 9.5 节。

**粉线与激光位置不重合？** 测量马达偏移，见 第 9.6 节。

**更换粉料或打印件后效果变化？** 为每套组合建立组件档案（第 9.3 节）；日常小幅漂移使用快速校准（第 9.4 节）。

**火药爆破风格每次生成的火花是否不同？** 不会。同一文件每次生成的 G-code 完全一致。
