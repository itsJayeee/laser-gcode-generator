# LaserGRBL G-code 生成器 · 使用手册

适用版本：**v1.18.0** ｜ [English version](MANUAL.en.md) ｜ 本手册随每次版本发布同步更新，历史改动见 [CHANGELOG](../CHANGELOG.md)。

这个工具是**一个 HTML 文件**，用浏览器打开就能用（推荐 Chrome/Edge），不用安装任何东西。它是为机械臂绘画的工作流做的：振动马达撒火药粉 + 激光点燃，两个工具配合；也可以当普通的激光雕刻/切割 G-code 生成器用。

## 先认识几个词

手册里会反复出现这几个词，看不懂的时候回来查这张表：

| 词 | 意思 |
|---|---|
| **G-code** | 机器能读懂的指令文件，一行一条命令，告诉机械臂"走到哪、开多大功率" |
| **.nc 文件** | G-code 存成的文件，下载后喂给 LaserGRBL 运行 |
| **S 值** | 一条指令里的"力度"数字。激光 = 功率大小，马达 = 振动强度 |
| **$30** | 机器里的一项设置，代表 S 值的满格是多少。LaserGRBL 默认 1000 |
| **功率% 和 S 的换算** | 功率% = S ÷ $30 × 100。$30=1000 时，S450 = 45%，S45 只有 4.5%，别看错位数 |
| **F 值** | 走线速度，单位毫米/分钟。F600 = 每分钟走 60 厘米 |
| **振幅** | 撒粉马达抖动的强度（也用 S 值表示）。抖得越猛，粉线越粗 |
| **M3 / M4** | 两种开激光/马达的方式。M3 = 力度恒定；M4 = 机器在加减速时自动调整力度。撒粉永远用 M3，激光雕刻一般用 M4 |
| **M0** | "暂停等人"指令。双工序中间靠它停下来，让你换工具头 |
| **purge（预冲）** | 正式撒粉前，先在旁边空撒几秒，把管子里"睡着"的粉唤醒 |

## 1. 快速上手

1. 双击打开 `gcode_generator.html`；
2. 在顶部选择**作业模式**（激光 / 振动马达 / 双工序）；
3. 把 SVG 文件拖进导入区；
4. 在"图层参数"里给每个颜色图层设置参数；
5. 等预览刷新（复杂图形会在后台算，界面不会卡）；
6. 点"下载"得到 `.nc` 文件，喂给 GRBL 运行。

**最简单的例子**：在 Illustrator 或 Inkscape 里画一个黑色描边的圆，导出 SVG，拖进工具 → 自动出现一个黑色图层 → 路径模式选"描边" → 功率 30%、速度 1800 → 下载。生成的 G-code 会沿着圆走一圈。

## 2. 导入文件（SVG）

不管你用 Illustrator、Figma 还是 Inkscape 画的图，只要线条颜色不同，导入后就会自动分成不同的图层——不需要做任何特殊设置。图里用了几种颜色，就得到几个图层，每个图层的参数都可以单独设。

> 示例：想让"先撒粉的笔画"和"只用激光的细节"分开控制，在设计软件里把它们画成两种颜色（比如红色和黑色）就行，导入后就是两个独立图层。

## 2.5 参数记忆与工程文件

**自动记忆**：所有全局设置和每个颜色图层的参数（功率/速度/模式/笔画风格等）会自动记在这台电脑的浏览器里。刷新页面、明天再开，都会原样恢复；重新导入用了相同颜色的 SVG 时，每个颜色自动套用上次的参数——"红色 = 构造线 S550 F600"这类习惯设一次就一直有效。

**工程文件**：导入区的"保存工程"把 **SVG 图形 + 全部参数（含撒粉档案）** 打包成一个 `.json` 文件下载；"载入工程"一键完整恢复。不同作品、不同参数方案各存一个文件，可以长期保存、换电脑用。注意：清除浏览器数据会把自动记忆清掉，重要参数请存成工程文件。

**工程命名**：点"保存工程"会弹出输入框让你给工程起名（默认用 SVG 的文件名），文件按 `工程名.json` 下载；名字也存在工程里，下次保存自动带出。

**G-code 文件名**：下载的 `.nc` 文件自动用导入 SVG 的文件名——`dragon.svg` 生成 `dragon.nc`。载入工程后同样生效。校准测试图仍叫 `calib.nc`。

## 3. 全局设置

| 设置 | 说明 |
|---|---|
| 输出宽度 (mm) | 成品的实际宽度，高度按原图比例自动算 |
| 原点 | 左下角（坐标全为正数）或居中（原点在图形中心） |
| S 上限 (=机器里的$30) | 要填得和机器里的 `$30` 设置一样，否则功率百分比会不准。LaserGRBL 默认 1000。功率/振幅输入框旁边会实时显示对应的 S 值 |
| 空程 G0 | 抬笔快速移动的速度，用来估算时间 |
| 气泵/风扇 (M8/M9) | 勾上后在开头开、结尾关 |
| 加工前走边框对位 | 正式开始前，机器先用零功率沿着图形外框走一圈，让你确认位置和大小对不对 |
| 以当前停的位置为起点 (G92) | 把机械臂**现在停的地方**当成这次作业的起点。起点不固定的大画布必开 |
| 马达偏移 dX/dY | 撒粉喷口和激光光点不在同一个位置，差多少填多少，见 §9.6 |
| 撒粉前预冲 (purge) | 正式撒粉前先到指定位置空撒几秒唤醒粉流，见 §9.5 |

---

**默认速度**：新图层默认 F=1000（激光）/ F=3000（马达）；切换设备或作业模式时恢复对应默认值。用过的颜色仍然优先恢复上次的参数。

**加工顺序**：图层**列表从上到下就是加工顺序**（角标 #1 #2 …）。点「编辑顺序」进入拖动模式（卡片折叠、可以拖），「完成」锁定。双工序里撒粉层永远先做，列表顺序只决定各自工序内部的先后。

**全选与连选**：图层启用列、测试页的导出列和选中列都有「全选」框；任何一列勾选框都支持 **Shift 连选**：点一个，按住 Shift 点另一个，中间一整段跟着变。

**其他**：改完参数光标自动回到原来的输入框（按 Tab 可以连续跳）；没有"生成"按钮（一直是自动生成的），下载按钮固定在左栏底部，下面一行显示"计算中 Ns…"或"就绪"。

## 4. 路径模式（激光图层）

每个图层可以单独选：

- **描边（outline）**：沿着画的轮廓走一遍。适合切割和线稿。
- **中线（centerline）**：粗笔画形状只沿中间走一遍。适合把描边字体变成单线雕刻。
- **填充（fill）**：闭合形状的内部用一条条平行线扫满。参数见 §5。
- **加粗（thicken）**：把单线向两边加宽成有宽度的笔画，再填满。适合单线字体、手写路径。参数见 §6。
- **圆圈（circles）**：沿着线条每隔一段画一个圆圈，原来的线不画。圆圈**大小**和**间隔**都可以选固定或随机（随机的结果同一个文件每次生成都一样）；勾上"填充圆圈"就是实心圆，配一个**填充密度**（mm，数字越小填得越实）。

---

## 5. 填充参数

- **间距 (mm)**：相邻扫描线之间隔多远。表面雕刻常用 0.1~0.2；想刻透厚材料用 0.05 加多遍。
- **线迹方向**：
  - **固定角度**：所有线朝同一个方向，传统方式。
  - **垂直于笔画**：每条线都横着切过笔画，长度约等于笔画的宽度。**这是用来解决"厚材料上有的地方刻得透、有的刻不透"的**——长线中段机器全速跑、烧得浅，短线来不及加速、烧得深；朝向不同的笔画受热就不一样。改成"垂直于笔画"后所有线一样短，处处烧得一样深。转角和交叉的地方会自动处理好，不会漏也不会重。
- **兜底**：太"胖"的形状（比如实心圆盘，不像笔画）找不出中线，会自动改回固定角度填充。
- **填充+描边**：勾上后，填完再沿轮廓描一圈，边缘更整齐。

> 示例配方（厚卡纸刻字、之前刻不匀的场景）：间距 0.05、线迹方向选"垂直于笔画"、S30 F1800、雕刻模式（M4），并确认机器里 `$32=1`。

## 6. 加粗模式与笔画风格

**笔画宽度**滑块设定基准宽度（mm）。**笔画风格**决定粗细沿着笔画怎么变化：

| 风格 | 效果 | 适用 |
|---|---|---|
| 均匀 | 从头到尾一样粗 | 标准粗线 |
| 两端收锋 | 起笔收笔平滑收细，像钢笔入锋出锋 | 手写感 |
| 书法笔锋(斜切) | 粗细跟着笔画方向变（横细竖粗），**笔锋角度**可调：30° 是西文斜体的经典角度，0° 接近宋体笔意 | 书法字 |
| 毛笔 | 收锋 + 笔锋叠加 | 签名、题款 |
| 火药爆破 | 粗细随机起伏 + 边缘灼烧短刺 + 周围飞溅火花。同一个文件每次生成的结果完全一样，不会这次一个样下次一个样 | 爆炸/火药美学 |

加粗的填充同样可以选"垂直于笔画"方向，而且短线的长度会跟着当地的粗细走——收锋的地方短线自动变短，烧得依然均匀。闭合的路径没有起笔收笔，收锋会自动变成均匀（毛笔变成纯笔锋）。

## 7. 作业模式

界面顶部第 0 节选这次作业的模式，界面只显示这个模式用得到的设置：

| 模式 | 行为 |
|---|---|
| **激光雕刻** | 所有图层都是激光；撒粉相关的设置都藏起来；材料预设可用 |
| **振动马达撒粉** | 所有图层都是撒粉；材料预设藏起来（那是激光材料的概念）；马达偏移藏起来（只用一个工具时，用"以当前位置为起点"就够了）；purge 可用 |
| **双工序（先撒粉后激光）** | 每个图层单独选设备；所有设置可见；生成的 G-code 分两段，中间 M0 暂停换工具 |

模式会记住，下次打开保持上次的选择。

## 8. 设备与双工序（机械臂 撒粉+激光）

每个图层顶部有**设备**选项：**激光** 或 **振动马达（撒粉）**。两个工具接的是同一路控制线，所以要按"先做完一种、停下换工具、再做另一种"的流程生成：

```
G92 X0 Y0            ← 可选：以当前位置为起点
(purge 预冲)          ← 可选
; PHASE 1 / POWDER   ← 全部撒粉图层（M3 恒定，坐标已含马达偏移）
M0                   ← 暂停：换上激光头，在 LaserGRBL 里按继续
; PHASE 2 / LASER    ← 全部激光图层（坐标不带偏移）
```

撒粉图层永远排在激光前面，跟列表顺序无关。只用一种设备时不会出现 M0。

## 9. 撒粉图层详解

### 9.1 工作原理

激光像"细笔填色"（来回扫描把面积填满），撒粉像"粗笔一笔过"——粉线的粗细由振幅直接控制。**中线**模式下，马达图层只沿线条中间走一遍（开放的线原样走；闭合形状自动找出中间线），粗细节奏全部编码在沿途逐段变化的 S 值（=振幅）里。撒粉用 **M3 恒定模式**而不是 M4：M4 会在加减速时把振幅也降下来，粉流就不稳了。

**撒粉路径模式**：马达图层有四种路径模式——**描边**（默认：沿轮廓原样走一遍，振幅恒定）、**中线**（上面说的走中间、带粗细节奏）、**填充**（闭合形状内部铺平行粉线，振幅恒定；粉线本身有几毫米宽，间距建议 ≥2mm）、**圆圈**（圆点撒粉：沿着线每隔一段停一个点，开着振动停留几秒，粉自己堆成一个圆点。间隔和每点停留时间都可以固定或随机；点的大小由停留时间和振幅决定，具体多大要实测）。描边/填充/圆圈模式的振幅直接用「振幅%」一个值。

### 9.2 粉线粗细节奏 → 振幅

选一种笔画风格（均匀/收锋/笔锋/毛笔）决定设计上的粗细节奏，然后自动换算成振幅：设计里最细的地方用你设的最小振幅，最粗的地方用最大振幅，中间的按比例取。这样就算设计里粗细差别很小，也会被拉开成硬件能表现出来的最大反差。

**均匀笔画**：选"均匀"时整条线一样粗，界面只显示一个**「振幅 %」**框，G-code 直接用这个值；最小/最大/粗细反差/提前量只在变宽的笔画（收锋/笔锋/毛笔）下才出现。

- **最小/最大振幅 %**：没有组件档案时用的振幅范围；
- **粗细反差**：把反差再夸张一点或压平一点。调大 → 细的地方更细（笔锋更尖）；调小 → 整体更饱满。默认 1（不夸张）；
- **提前量 (mm)**：粉从喷口落到布上有一点延迟，这个参数让振幅的变化**提前**这么多距离发出，正好抵消延迟。笔画末端拖粉就调大它（从 3mm 试起）。

### 9.3 组件档案

每套"3D 打印撒粉件 + 粉料"的脾气都不一样（出粉粗细、抖多小就完全不出粉、抖多大就到头了）。**组件档案**保存每套组合实测出来的"振幅→线宽"对应关系，图层里切换档案就自动按那套的实测数据换算。选"不用校准数据"就不查曲线，直接按振幅范围换算。

### 9.4 校准向导

马达图层点"校准向导…"：

1. **生成测试图案 G-code** → 下载 `calib.nc`（8 条振幅从 20% 到 90% 逐级递增的直线，每条 30mm）；
2. 装粉运行；
3. 用卡尺量每条粉线的实际宽度，填进表格（**没出粉的行填 0**，工具会自动记住"这么小的振幅出不了粉"）；
4. 保存档案。

> 示例校准结果：30%→1.2mm、50%→2.0mm、70%→3.1mm、80%→3.5mm、20% 填 0（出不了粉）。之后这个档案下，振幅永远只在 30~80% 这个有效范围里取。

**快速漂移校准**（每天开工用）：粉量、湿度会让出粉量慢慢变。用基准振幅（比如 60%）画一条线，量出宽度填进"今日实测"，点缩放按钮——整条曲线按比例修正，十秒完成，不用重跑全套。

**保存机制**：向导里的所有改动（表格数值、新建/删除档案、漂移校准）都是草稿，点「保存档案」才真正生效、参与 G-code 生成；带着没保存的改动关窗会弹确认。误删了档案，直接关窗就能回滚。

### 9.5 Purge 预冲

停机一段时间后，管子里的粉是"睡着"的，直接开画第一笔会残。勾上 purge 后，正式路径开始前会自动先到你指定的坐标（选画面外的废料区）空撒指定秒数，唤醒粉流。

### 9.6 马达偏移标定

喷口和激光光点的物理位置不一样，必须量一次：低功率激光画一个小十字 → 换撒粉头在**同一坐标**撒一个十字 → 量两个十字中心差多少 → 填进 dX/dY。之后撒粉工序的坐标自动平移，粉线和激光就会走布上同一条线。只要不拆装工具头就不用重量。

## 10. 材料预设

"材料预设"下拉可以一键套用某种 材质/厚度/火药/效果 对应的 模式/功率/速度/遍数。预设管理器支持新建、从当前图层保存、删除、导入导出 JSON、恢复内置库。数据记在这台电脑的浏览器里。

**火药栏**：预设里有一个自由填写的"火药"字段（建议写法：厂家·颜色·粗细·批次，如"XX厂·黑·细·2026-07批"）。点燃参数取决于 **火药 × 画布** 的组合，没法拆开来推算——一条预设就记录一个实测过的组合。老规矩：预设里的数值在实测之前都只是估计值。

**草稿与保存**：管理器里的所有改动（编辑、新建、删除、导入、载入内置）都只是**草稿**，点底部「保存预设」才真正生效。带着没保存的改动关窗会弹确认——改错了删错了，直接关窗就能回滚。「导出 JSON」导出的是当前草稿。

## 10.5 测试页签

左栏顶部有两个页签：**「创作」**（完整 SVG 工作流）和**「测试」**。切到「测试」，左栏整个变成测试工作台，**一进去就自动生成 G-code**，之后任何改动实时更新。用来做材料/火药定标：

**T1 · 布局与步进**：像在 Google Docs 里插表格一样，滑格子选行×列（或直接填数字，最多 20×20）；设线长/行距/列距；选设备（激光/马达）。S、F（马达是振幅%）各有**行步进和列步进**：每格的值 = 起始值 + 行数×行步进 + 列数×列步进，不想变的方向填 0。「填充S / 填充F / 填充振幅」是三个独立按钮，只重算对应那一项，绝不动你手改过的其他值。激光的 S 直接填数值（上限就是你设的 $30），M3/M4 可选；马达每条线填振幅%、F 固定一个值（自动用 M3）。

**T2 · 线列表**：每条线一个颜色，预览和列表的色块一一对应。勾选框 = **要不要导出这条线**（不勾就不进 G-code）；**点卡片本身 = 选中**（整卡高亮），Shift 点连选，点勾选框或数字框不会触发选中；每条线的 S/F（或振幅%）都能单独改，改完立即重新生成。**在预览画布上按住 Shift 拖 = 框选**：拉出的矩形碰到的线全部选中（选中的线在预览里加粗），拖一横条=选一行、一竖条=选一列；普通拖拽还是平移画面。

**T3 · 组**：选中几条线 → 点「把选中的线成组」。组可以改名；组的勾选框一键开关全组的导出；在组里填一次 S/F/振幅就批量套用到整组；组里的线在预览里统一用组的颜色；「解组」还原。G-code 注释里带组名（`; r2c3 [组1]: S500 F900`）。

其他：顶部统计栏（空程/加工长度/预估耗时/行数）同样生效（网格按格子顺序走，不做空程优化）；第 1 行在下面（Y=0）；每格有注释，还有一张可复制的参数对照表；页签选择、布局、每线参数、导出勾选、分组全部自动记住；「下载 testgrid.nc」在测试面板底部。

**弹窗说明**：整个工具的弹窗（保存工程的命名框、各种确认/提示）都是页面自己画的，不用浏览器的弹窗，所以不受浏览器"阻止对话框"设置影响。

## 11. 预览与统计

- 滚轮缩放、拖拽平移、双击复位；
- **绿色虚线**是空程（抬笔快速移动）的路径；路径特别多（超过 8000 条）时自动隐藏以保流畅；
- 马达图层画成**变宽的线**，直接看到粉线的粗细节奏；
- 鼠标悬停在图层卡片上，预览里高亮那一层；
- 统计栏显示：优化前/后空程、节省比例、加工长度、预计时间、G-code 行数。

**性能说明**：所有大计算都在后台做，拖参数不卡界面；连续改动时只算最新那一次。只改功率/速度/遍数这类不改变走线形状的参数时，几乎瞬间出结果。特别长的 G-code 在文本框里只显示开头一段，**下载的文件永远是完整的**。

## 13. 常见问题

**导入 SVG 只有一个黑色图层？** 老版本的问题，早已修复。还出现的话，检查一下 SVG 是不是真的只用了一种描边颜色。

**厚材料有的地方刻不透？** 见 §5：填充线迹方向改"垂直于笔画"，确认机器里 `$32=1`、雕刻用 M4。还不透就加遍数，不要无限降速。

**"垂直于笔画"填充结果是空的？** 图形太"胖"、不像笔画，工具已自动改回固定角度（正常现象）。

**撒粉笔画末端有一坨粉？** 调大提前量（§9.2）。

**第一条粉线是残的？** 开 purge 预冲（§9.5）。

**粉和激光烧的位置对不上？** 量一次马达偏移（§9.6）。

**换了粉/换了打印件效果全变？** 每套组合建一个组件档案（§9.3），日常的小漂移用快速校准（§9.4）。

**火药爆破每次生成的火花不一样？** 不会——同一个文件每次生成的 G-code 完全一样。
